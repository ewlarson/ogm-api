OGM Viewer Integration Examples

This page demonstrates different ways to integrate the OGM viewer with your API.

1. Direct iframe Embedding

Embed the viewer directly using an iframe:

<iframe src="http://localhost:8000/api/v1/resources/YOUR_RESOURCE_ID/viewer?embed=true" width="100%" height="600px" frameborder="0"> </iframe>

2. Web Component Usage

Use the OGM viewer as a web component in your HTML:

<script type="module" src="https://unpkg.com/ogm-viewer"></script> <ogm-viewer record-url="http://localhost:8000/api/v1/resources/YOUR_RESOURCE_ID/ogm"></ogm-viewer>

3. Dynamic Configuration

Get viewer configuration programmatically:

fetch('/api/v1/resources/YOUR_RESOURCE_ID/viewer/config') .then(response => response.json()) .then(config => { console.log('Viewer config:', config); // Use config.embed_html, config.web_component_usage, etc. });

4. Theme Customization

Customize the viewer theme (light, dark, or auto):

<iframe src="http://localhost:8000/api/v1/resources/YOUR_RESOURCE_ID/viewer?theme=dark&embed=true" width="100%" height="600px" frameborder="0"> </iframe>

5. Custom Embed Snippet

Get a custom embed snippet with specific dimensions:

fetch('/api/v1/resources/YOUR_RESOURCE_ID/viewer/embed?height=800px&width=90%') .then(response => response.text()) .then(html => { document.getElementById('embed-container').innerHTML = html; });
